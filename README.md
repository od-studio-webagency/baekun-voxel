# 백운고 몬스터 디펜스

광양백운고등학교를 복셀(마인크래프트 풍) 3D 맵으로 만든 1인칭 활쏘기 웨이브 디펜스 데모입니다.
AI 진로 교육 강연 시연용으로 만들었으며, 코드는 대부분 AI 코딩 에이전트가 작성했습니다.
판타지 밤하늘(은하수·유성·달·창문 불빛) 아래에서 몰려오는 몬스터로부터 학교를 지키세요!

▶ 플레이: https://osg1935.github.io/baekun-voxel/

설치 없이 브라우저(Chrome·Safari·Edge)에서 바로 실행됩니다. Three.js r169는 `vendor/`에 포함되어 있어 외부 CDN을 쓰지 않습니다.

## 조작
| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| 마우스 | 시점 (게임 시작 시 포인터 잠금) |
| 좌클릭 | 화살 발사 (길게 누르면 차징 → 더 멀리·강하게) |
| Space | 점프 |
| Shift | 달리기 |
| Esc | 일시정지 |

휴대폰·태블릿: 왼쪽 아래 조이스틱으로 이동, 화면 오른쪽 드래그로 시점, "발사" 버튼으로 공격.

## 규칙
- 웨이브마다 슬라임(10점)·좀비(20점)가 몰려오고, 5웨이브마다 보스(100점)가 나옵니다.
- 몬스터에 닿으면 HP가 줄고, 웨이브를 클리어하면 HP +20. HP가 0이 되면 게임 오버.
- 화면 밖 몬스터는 가장자리의 빨간 삼각형으로 표시됩니다.

## 버프 오브
몬스터 처치 시(25%) 또는 웨이브 중 주기적으로 운동장에 빛나는 오브가 나타납니다. 걸어가서 먹으면 8–10초 동안 버프가 걸리고 하늘 색이 바뀝니다.

| 버프 | 효과 |
|---|---|
| 멀티샷 | 화살 여러 발 부채꼴 발사 |
| 래피드파이어 | 누르고 있으면 연사 |
| 관통 화살 | 여러 몬스터 관통 |
| 폭발 화살 | 맞은 곳 주변 범위 피해 |
| 슬로모션 | 몬스터 느려짐 |
| 힐 | HP 회복 |

## URL 옵션
주소 뒤에 붙여서 사용합니다. 예: `https://osg1935.github.io/baekun-voxel/?q=low`

| 옵션 | 설명 |
|---|---|
| `?q=min` / `?q=low` / `?q=high` | 화질 고정 (기본: 자동 — 시작 직후 프레임 측정 후 결정) |
| `?sens=1.5` | 마우스 감도 배수 (기본 1) |
| `?debug=1` | FPS·드로우콜·삼각형 수·프레임타임 그래프 표시 |
| `?touch=1` | 터치 조작 UI 강제 표시 |
| `?lookdiag=1` | 마우스 입력 진단 오버레이 |

## 로컬 실행
```bash
python3 -m http.server 8000
# http://localhost:8000/ 열기 (file:// 로 직접 열면 ES 모듈 제한으로 동작하지 않음)
```
